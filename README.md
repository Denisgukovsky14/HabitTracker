# Привычки — трекер привычек на .NET MAUI

Минималистичное кроссплатформенное приложение для ежедневного отслеживания привычек.
Отмечаешь выполненное за день и видишь серию дней подряд и историю за последние 12 недель.

## Возможности

- Добавление и удаление привычек
- Отметка выполнения за сегодня в одно касание
- Серия дней подряд 🔥: не сгорает, пока не закончился текущий день
- Экран привычки: текущая серия, рекорд, всего отметок, процент за 30 дней
- Сетка последних 12 недель: можно отметить пропущенный день задним числом
- Светлая и тёмная тема (переключатель 🌙/☀️, выбор запоминается)
- Работает полностью офлайн: данные хранятся локально в SQLite

## Стек

| | |

## Структура

```
HabitTracker/
├─ Models/          Habit и Check — таблицы SQLite
├─ Services/
│  ├─ HabitDatabase.cs   работа с базой: привычки и отметки по дням
│  └─ Streaks.cs         подсчёт серий и склонение «день/дня/дней»
├─ ViewModels/      логика экранов (MainViewModel, HabitViewModel)
├─ Pages/           разметка XAML: главный экран и экран привычки
└─ Resources/Styles палитра светлой и тёмной темы
HabitTracker.Tests/ юнит-тесты логики серий
```

## Как это работает

Каждая отметка — это запись «привычка + день». Уникальный индекс в базе не даёт отметить привычку дважды за день; повторное нажатие снимает отметку.
Серии считаются по набору отмеченных дней в `Streaks.cs`. Это чистая логика без зависимостей от MAUI, поэтому она покрыта тестами отдельно.

## Запуск

1. Visual Studio 2022 (17.12+) с нагрузкой «.NET MAUI»
2. Открыть `HabitTracker.sln`
3. Выбрать **Windows Machine** или Android-устройство и запуститься

Тесты:
```
dotnet test HabitTracker.Tests
```
